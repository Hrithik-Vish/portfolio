# Portfolio

Plain HTML, CSS and JavaScript. No build step. Deploy the folder as is (Vercel, Netlify, GitHub Pages).

- `index.html` page structure and static sections (hero, milestones, about, contact)
- `projects.js` **all case-study content**. Edit or add projects here; the page rebuilds itself
- `main.js` behaviour and the CONTACTS table (links, copy values)
- `style.css` design tokens are at the top (colours, fonts) for both light and dark
- `images/` screenshots, logo, original flowcharts. `resume.pdf`, `og-image.png`

Before publishing: update the two `og:` URLs in `index.html` if the domain changes, and re-check
the status lists in `projects.js` so they match what is actually built.
