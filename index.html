GeoCoderZ [2813ms → 1391ms]

Automatically identifies the correct location from ambiguous incident reports — like two towns sharing a name — through a four-stage pipeline backed by a 780K+ row gazetteer. A two-level cache cuts repeat-lookup time roughly in half, and a scoring engine weighs regional context over guessing by population alone.

Schema: 6-table PostgreSQL/PostGIS design with a 121K+ row alternate-name table feeding candidate lookup. Disambiguation scoring combines region hints, spatial proximity, and population priors, with confidence capped on unsupported matches — verified by a 21-case automated test suite (unit + live integration). Out-of-scope queries degrade gracefully via a local-to-Nominatim fallback, returning a stated reason instead of a silently wrong coordinate.
